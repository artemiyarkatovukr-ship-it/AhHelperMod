# Скелет Fabric-мода (Minecraft 1.21.11)

Минимальный, но рабочий шаблон мода. Ничего не делает, кроме одной строчки
в лог при запуске — это специально, чтобы первая сборка на GitHub Actions
точно прошла без ошибок. Дальше уже добавляешь свою логику.

## Как собрать через GitHub (без установки чего-либо на телефон)

1. Создай новый репозиторий на github.com (можно прямо с телефона в приложении/браузере).
2. Залей туда ВСЕ файлы из этого архива, сохранив структуру папок
   (включая скрытую папку `.github`, там лежит workflow для сборки).
3. Открой репозиторий → вкладка **Actions**.
4. Если сборка не запустилась сама — зайди в workflow "Build Mod" → **Run workflow**.
5. Подожди 2-5 минут, пока идёт сборка.
6. Открой завершённый запуск → внизу раздел **Artifacts** → скачай `mod-jar`.
7. Внутри `mod-jar.zip` будет готовый `.jar` — это и есть твой мод,
   кидаешь его в папку `mods` клиента с Fabric Loader.

## Как загрузить файлы с телефона на GitHub без Termux

Проще всего:
- В приложении GitHub или в браузере зайди в свой пустой репозиторий
- "Add file" → "Upload files" → выбери все файлы/папки из архива
- Важно: GitHub веб-загрузка иногда режет пустые папки — раз в проекте все
  папки содержат файлы, проблем быть не должно.

## Если хочешь писать код мода прямо с телефона

Открой репозиторий на github.com, нажми клавишу `.` (точку) на клавиатуре —
откроется облегчённый VS Code прямо в браузере, можно редактировать
`ExampleMod.java` и другие файлы, коммитить — и Actions пересоберёт мод
автоматически.
